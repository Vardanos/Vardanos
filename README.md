# Vardan Harutyunyan

Co-founder and Chief AI Officer at [Denovo Sciences](https://denovosciences.ai), an AI-first company doing small-molecule drug discovery with deep reinforcement learning and physics-based simulation.

My work spans de novo molecular design, generative chemistry and structure-based drug design.

## Open source

- [HADES](https://github.com/denovosciencesai/HADES): a machine-learning oral drug-likeness score for small molecules ([paper](https://doi.org/10.1021/acs.jcim.5c02953))
